A note on LinkedIn / Indeed

LinkedIn and Indeed don't offer a public API for pulling listings or submitting applications, and both explicitly prohibit automated scraping/applying in their terms — accounts that do it get banned. This tool intentionally doesn't touch either site programmatically. When you find something on LinkedIn/Indeed manually, use the Prep Sheet feature (paste the job title/description into a manual entry below) to get your tailored answers ready, then apply yourself on the real site.

Data & security

Everything (profile, answers, tracker, sources) is encrypted with a key derived from your password (PBKDF2 + AES-GCM via your browser's Web Crypto API) and stored only in this browser's local storage. Nothing is sent to any server except the read-only job-board API calls you configure in Sources. There is no password recovery — if you forget it, the encrypted data is unreadable and you'll need to wipe.
